   
# 一、雅可比行列式的定义（二元）

设有坐标变换：
$$\begin{cases} x=x(u,v)\\ \\
 y=y(u,v) \end{cases}$$
雅可比行列式定义为：
$$J=\frac{\partial(x,y)}{\partial(u,v)}= \begin{vmatrix} x_u & x_v \\ y_u & y_v \end{vmatrix} = x_u y_v - x_v y_u$$
本质：**局部微元的伸缩比例系数**
# 二、从零几何推导（核心）
## 1. uv 平面微小矩形
uv 平面取微元矩形，两边向量：
$$d\vec{s}_u=(du,0),\quad d\vec{s}_v=(0,dv)$$
面积：$$dudv$$
## 2. 映射到 xy 平面（一阶泰勒近似）

变换后的两个切向量：
$$\begin{cases} d\vec{r}_u = (x_u du,\; y_u du)\\ d\vec{r}_v = (x_v dv,\; y_v dv) \end{cases}$$
映射后的微元变成**平行四边形**。
## 3. 平行四边形面积 = 二维叉乘
两向量围成面积：

$$d\sigma = |x_u du\cdot y_v dv - y_u du\cdot x_v dv|$$

整理：
$$d\sigma = |x_u y_v - x_v y_u|\,dudv$$
## 4. 代入雅可比定义
$$d\sigma = \left|\frac{\partial(x,y)}{\partial(u,v)}\right|dudv = |J|dudv$$
**这就是雅可比换元公式的唯一来源**

# 三、最关键的正反变换关系（必考）
## 1. 正向变换 (u,v)→(x,y)

$$dxdy = \left|\dfrac{\partial(x,y)}{\partial(u,v)}\right| dudv$$
## 2. 逆向变换 (x,y)→(u,v)
雅可比倒数性质：

$$\frac{\partial(x,y)}{\partial(u,v)}\cdot \frac{\partial(u,v)}{\partial(x,y)} = 1$$
所以：
$$dudv = \left|\dfrac{\partial(u,v)}{\partial(x,y)}\right| dxdy$$
# 四、无换元的特殊情况
不做任何换元：$$u=x,\;v=y$$
$$J=\frac{\partial(x,y)}{\partial(x,y)}= \begin{vmatrix}1&0\\0&1\end{vmatrix}=1$$

得到：
$$d\sigma=dxdy=1\cdot dxdy$$

**结论：平面不换元时，雅可比恒为 1**

# 五、彻底区分：平面雅可比 VS 曲面雅可比
## 1. 平面二重积分（2 D→2 D）
**单个雅可比绝对值**
$$d\sigma = |J|dudv,\quad J=\dfrac{\partial(x,y)}{\partial(u,v)}$$
## 2. 曲面面积微元（2 D 参数→3 D 曲面）
**三个雅可比平方和开根号**
$$dS=\sqrt{ J_{yz}^2+J_{zx}^2+J_{xy}^2}\,dudv$$
$$J_{yz},J_{zx},J_{xy}$$ 是三组不同配对的二元雅可比
**曲面没有“单个雅可比”，永远是组合式**
# 六、终极一句话总结
- **平面换元：面积微元 = 单个雅可比绝对值 × 新变量微元**
    
- **平面不换元：雅可比=1，dσ=dxdy**
    
- **曲面面积：三组雅可比平方和开根号，和平面 J 不是一回事**
