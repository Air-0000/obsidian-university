# 1.叠加定理的定义
当电路中存在多个电源（电流/电压）时，一个元件的电压/电流，可以表达成**累加**的形式

单个累加项 即这个元件在只有**对应电源的作用的情况下**的电流，电压

在计算单个电源的时候要把其他的电源全部去掉，
1. 电流源直接断路
2. 电压源直接短路


# 2.替代定理的定义（等效替代）
# 2.1 常规纯电阻电路
说白了，替代定理就是**等效替代**

已知一条支路的**电压-电流**，那就可以用一个电源和电阻直接等效替代

但是这个不能在包含电容，电感的支路里面会有所变化

# 2.2 直流稳态
- 电容——〉开路
- 电感——〉短路

此时也可以用这几个定理，但题目一般会单独标注**直流稳态**；日常课后 / 考试基础题，基本只出纯电阻电路。

# 2.3 交流/动态电路
含电容、电感的交流电路（正弦稳态），引入**阻抗**后，叠加、替代、戴维南等定理**依然成立**，只是计算从电阻运算变成**相量运算**，难度会上升，一般放在后面章节学习。
