   #contrast
### 数据存储
```
地址:     0x00    0x01    0x02    0x03
         ┌──────┬──────┬──────┬──────┐
字值:    │ 0x12 │ 0x34 │ 0x56 │ 0x78 │
0x12345678  ↑                  ↑
          高字节               低字节
```
**高字节在低地址**，所以叫"大端"。
### 小端序对比
```
地址:    0x00    0x01    0x02    0x03
        ┌──────┬──────┬──────┬──────┐
字值:   │ 0x78 │ 0x56 │ 0x34 │ 0x12 │
        ↑                       ↑
       低字节                   高字节
```
### 大端优势

|特点|说明|
|---|---|
|**人读友好**|地址 0 x 00 就是最高字节，直观|
|**字符串比较**|首字符在低地址，可用指针比较|
|**网络协议**|经典 MIPS/网络序常用大端|
|**调试方便**|看内存直接是高位在前|
### 小端优势

|特点|说明|
|---|---|
|**类型转换简单**| `(int)char` 直接读，低地址就是低字节|
|**整数运算**|符号位在固定位置|
|**x 86 兼容**|大多数 PC 用小端|

### 实际例子
```
0x12345678 存在地址 0x100

大端: [0x100]=0x12  [0x101]=0x34  [0x102]=0x56  [0x103]=0x78
小端: [0x100]=0x78  [0x101]=0x56  [0x102]=0x34  [0x103]=0x12
```
