# 1.module 的输入类型（wire/reg）选择
## 1.1 PC 输出从 reg 改成 wire

> [!NOTE]
> PC 输出从 reg 改成 wire
> 
> 这不行！**PC 必须用 `reg` **

### wire vs reg

|类型|用途|能保存值吗|
|---|---|---|
| `wire` |组合逻辑，等号右边|❌ 不能|
| `reg` |时序逻辑，always 块里|✅ 能|

### 问题在哪

```verilog
// ❌ 错误：wire 不能在 always 块里赋值
wire [31:0] pc;
always @(posedge clk) begin
    pc <= pc + 4;  // 编译报错！
end

// ✅ 正确：reg 可以保存值
reg [31:0] pc;
always @(posedge clk) begin
    pc <= pc + 4;  // 可以
end
```

### 你的 PC 必须这样

```verilog
module ProgramCounter(
    input clk,
    input rst_n,
    input branch_decision,
    input [31:0] branch_target,
    output reg [31:0] pc   // ← 必须是 reg
);
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            pc <= 32'b0;
        else if (branch_decision)
            pc <= branch_target;
        else
            pc <= pc + 4;
    end
endmodule
```
## 1.2 PC 输出改回 reg，IM 的输入要不要和 PC 相同为 reg
> [!NOTE]
> 那我改成 reg，IM 里面也要输入改 reg 吗
> 
> **不需要**！IM 是**组合逻辑**，保持用 `wire`。

### 区别

| 模块             | 逻辑类型     | 用什么    | 原因                |
| -------------- | -------- | ------ | ----------------- |
| ProgramCounter | **时序逻辑** | `reg`  | 需要保存 pc 的值，更新靠时钟  |
| InstructionMem | **组合逻辑** | `wire` | 地址输入 → 立即输出，不需要保存 |
### 形象理解
```
ProgramCounter（时序）:
    像个计数器，按一下时钟按钮才变一次

InstructionMem（组合）:
    像个只读的表格，查哪个地址就出哪个数
    地址变了，输出立刻跟着变
```
### 代码对比
```verilog
// ProgramCounter - 时序逻辑
output reg [31:0] pc;           // 需要 reg 保存值
always @(posedge clk) begin
    pc <= pc + 4;
end

// InstructionMem - 组合逻辑
output [31:0] instruction;      // wire 就够
assign instruction = instr_mem[addr[9:2]];
```
### 记忆口诀
```
组合逻辑 → assign / always @(*) → wire
时序逻辑 → always @(posedge clk) → reg
```
## 1.3 用什么格式和 输入的是什么格式输出的无关，只和之后怎么处理有关
> [!NOTE]
> 所以用什么格式和输入的是什么格式输出的无关，只和之后怎么处理有关是吗
> 
对，**完全正确**！
### 关键看"怎么用"

|输出后怎么处理|用什么|
|---|---|
|连接到其他模块| `wire` |
|在 `always` 块里被赋值| `reg` |
### 和输入/输出类型无关
```
output [31:0] xxx;   // 输出可以是 wire 也可以是 reg，取决于你怎么用它
input [31:0] yyy;    // 输入永远是 wire（你只能读它）
```
### 举例
```verilog
// 场景1：PC 输出到其他模块
output reg [31:0] pc;        // 因为 always @(posedge clk) 里要赋值
always @(posedge clk) begin
    pc <= pc + 4;
end

// 场景2：IM 输出到其他模块
output [31:0] instruction;   // 因为只是 assign 赋值
assign instruction = ...;

// 场景3：中间信号
wire [31:0] add_result;      // ALU 结果直接连出去
assign add_result = a + b;
```
### 判断口诀
```
输入一定是 wire（你不能改别人的值）
输出看它会不会被"记住"：
  - 需要记住/更新 → reg（时序）
  - 直接传出去 → wire（组合）
```
