# Obsidian University 🎓

大学学习笔记库（Obsidian Vault）。

## 内容

- **每日笔记**：按日期组织的学习记录（`2026-05-05.md` 等）
- **University/**：课程笔记
  - `InClass` — 课堂笔记
  - `OutClass` — 课外学习
- **Excalidraw/**：数学与电路图解（二重积分、戴维南/诺顿定理、向量叉乘等）
- **简历经历记录.md**：个人简历与经历整理

## 使用

用 [Obsidian](https://obsidian.md/) 打开本仓库目录即可。推荐插件：

- **Excalidraw**：查看/编辑 Excalidraw 图解
- **Dataview**：笔记索引与统计

## 约定

- 笔记按 `YYYY-MM-DD（标签）.md` 命名，标签如 `todo`、`read`、`brain` 等
- 图统一放在 `Excalidraw/` 或各课程目录下
